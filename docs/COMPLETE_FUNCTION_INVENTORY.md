## 1. INVENTORY OVERVIEW & TAXONOMY

This document is the exhaustive inventory of every screen, widget interaction, input field, selection control, modal sheet, API endpoint, controller function, database operation, and notification event across the Sky Height Apartment ecosystem.

### Test ID Coding Scheme
- `AUTH-OWN-xxx` / `AUTH-TEN-xxx` / `AUTH-PUB-xxx`: Authentication, Session, Registration, Security
- `DASH-OWN-xxx` / `DASH-TEN-xxx`: Dashboards & Metric Summaries
- `ROOM-OWN-xxx`: Room Management, Capacity, Bed Allocation, Vacancy
- `TEN-OWN-xxx` / `TEN-PRF-xxx`: Tenant Management, Profile, Vacating, History
- `BILL-OWN-xxx` / `BILL-TEN-xxx`: Monthly Billing, Invoices, Adjustments, Arrears
- `PAY-OWN-xxx` / `PAY-TEN-xxx`: Payments, Cash Record, UPI Submission, Verification
- `MTR-OWN-xxx` / `MTR-TEN-xxx`: Electricity Sub-Meters, Reading Capture, Usage History
- `EXP-OWN-xxx`: Property Operational Expenses & Net Profit Analysis
- `CMP-OWN-xxx` / `CMP-TEN-xxx`: Maintenance Complaints & Helpdesk
- `NTF-OWN-xxx` / `NTF-TEN-xxx`: In-App Notifications, Announcements, Broadcasts
- `CHT-OWN-xxx` / `CHT-TEN-xxx`: Real-time Messaging (Private, Room, Community)
- `SET-OWN-xxx`: PG Global Configuration, UPI Setup, Tariff Management
- `API-xxx-xxx`: Direct Backend REST Endpoints, Validations, Status Codes, Cascades
